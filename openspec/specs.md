## 2. 功能模組清單

### 2.1 登入驗證模組
- 使用者選擇「部別 → 課別 → 人員」三層聯動下拉選單
- 輸入工號（8碼）作為密碼
- GAS 後端比對「人員工號」活頁中的工號欄位，username === password === 工號
- 登入成功後取得 token，儲存於 localStorage
- 基本資料（部別、課別、姓名）自動帶入點檢表單

### 2.2 點檢作答模組（RC / FC 兩種題型）
- **RC（直營店）**：標準題組，多選項單選
- **FC（加盟店）**：含跳題邏輯，特定選項觸發跳過後續項目
- 跳題邏輯：
  - `skip_items`：選項直接指定跳過的題目 ID
  - `第N、M項無需點檢`：跳過整個項目的所有題目（支援多項目）
  - `→填X`：跳到指定題，略過中間題目
- 照片上傳：僅「現場無法判斷(請拍照記錄)」選項觸發缺失說明欄位與照片上傳區

### 2.3 記錄查詢模組
- 依日期、店別、人員篩選歷史點檢記錄
- 支援「修改」（重新編輯答案）與「刪除」（需填刪除原因）
- 每次修改/刪除自動寫入 audit_log（含店名、操作人員、時間）

### 2.4 人員管理模組
- 新增單筆人員（姓名、課別、工號）
- 批次匯入 Excel（.xlsx）→ 寫入 GAS「人員工號」活頁（清空舊資料再寫入）
- Excel 格式：序號 / 部別 / 課別 / 工號（8碼）/ 姓名 / 職稱

### 2.5 題目維護模組
- 依月份維護 RC / FC 題目
- 新增 / 編輯 / 刪除題目與選項
- 支援選項跳題設定（skip_items）

## 5. 業務規則與邊界

1. **工號格式**：一律 8 碼，不足補前導零；GAS 比對時去除前導零（normId）避免 Sheets 數字轉換問題
2. **登入機制**：username = password = 工號（無獨立密碼，以工號即身份）
3. **Session 管理**：token 存於 localStorage，7天有效，401 自動登出
4. **人員匯入**：匯入前清空「人員工號」活頁舊資料，全量覆寫
5. **照片上傳**：上傳至 Google Drive 指定資料夾（FOLDER_ID），回傳檔案 URL 存入答案
6. **FC 照片驗證**：提交時若有「現場無法判斷」選項，必須填寫缺失說明，否則阻擋提交
7. **audit_log 店名**：刪除操作必須在刪除 inspection 列前先取得 store_name
